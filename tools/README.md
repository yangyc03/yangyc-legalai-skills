# Standalone Tools

This directory contains independently installable local utilities that are not Agent Skills and do not use a `.codex-plugin` adapter.

## Available tools

- [`finder-office-quick-actions`](finder-office-quick-actions/README.md) — macOS Finder Quick Actions for creating neutral Word/Excel files in a selected folder and moving selected items to the Desktop.
- [`wechat-chat-recording`](wechat-chat-recording/README.md) — macOS 本地微信聊天录屏整理工具，生成连续截图、可打印 PDF 与可检索 Word 文字稿。

Each tool documents its supported platform, dependencies, permissions, security boundary, validation and uninstall process. Source is maintained in this repository; downloadable archives are published through namespaced GitHub Releases.

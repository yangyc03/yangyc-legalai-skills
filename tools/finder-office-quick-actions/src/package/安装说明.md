# Finder 办公快速操作

- 版本：v1.0.0
- 维护者：Yingchao Yang（杨颖超）
- 许可证：Apache License 2.0
- 验证环境：macOS 26.5.2、Microsoft Word、Microsoft Excel

本工具提供三个 Finder 快速操作：

- 新建 Word 文档：右键恰好一个文件夹名称，在该文件夹内创建并打开 `.docx`。
- 新建 Excel 工作簿：右键恰好一个文件夹名称，在该文件夹内创建并打开 `.xlsx`。
- 移动到桌面：右键选中的文件或文件夹，移动到当前用户的桌面；同名时可选择保留两者、替换或取消。

这仍然是“右键选中的文件夹或项目”模式，不会出现在 Finder 空白处的右键菜单中。

## 环境要求

- 不需要 Xcode、Python、管理员权限或完全磁盘访问。
- 新建 Word、Excel 需要目标 Mac 已安装 Microsoft Word、Microsoft Excel。
- 安装包不包含宏、网络访问、账号、密码、客户资料或个人模板。
- 本发行包未经过 Apple Developer ID 签名或公证；只应从项目正式 Release 下载并核对 SHA-256，不要关闭 Gatekeeper。

## 推荐安装

1. 解压 ZIP，确认本说明、`校验清单-SHA256.txt`、三个快速操作和两个空白模板均存在。
2. 打开 `安装.command`。
3. 安装程序会先显示目标位置；输入 `y` 后才开始复制。
4. 如目标位置已有同名文件，安装程序会先备份，不会直接删除。
5. 在 Finder 中右键任一文件夹，选择“快速操作 → 自定”，启用：
   - 新建 Word 文档
   - 新建 Excel 工作簿
   - 移动到桌面
6. 首次运行时，只按系统实际提示授予必要的“自动化”或“文件与文件夹”权限；不要授予完全磁盘访问。

如果 macOS 阻止直接打开命令文件，不要关闭 Gatekeeper。可核对 ZIP 校验值后使用下面的手工安装方法。

## 手工安装

1. 在 Finder 中按 `Shift-Command-G`，输入 `~/Library/Services/`。
2. 将“快速操作”文件夹中的三个 `.workflow` 复制进去。
3. 再按 `Shift-Command-G`，输入 `~/Library/Application Support/FinderOfficeQuickActions/`。
4. 将“空白模板”文件夹中的两个文件复制进去。
5. 回到 Finder，通过“快速操作 → 自定”启用三个动作。

请勿直接双击 `.workflow`；部分 macOS 版本会把它导入“快捷指令”，而不是安装成 Finder 快速操作。

## 验收

请先在一个可丢弃的临时文件夹中验证：

1. 连续新建两次 Word，确认第二个文件带 `_02` 且不会覆盖。
2. 连续新建两次 Excel，确认第二个文件带 `_02` 且不会覆盖。
3. 选择一个可丢弃文件和文件夹，验证“移动到桌面”。
4. 制造桌面同名项目，分别验证“保留两者”“替换”“取消”。
5. 验证“替换”时旧项目进入废纸篓，而不是永久删除。

## 卸载与恢复

打开 `卸载.command`。卸载程序只移动本工具的三个工作流和两个模板到一个带时间戳的可恢复目录，不会删除使用本工具创建的文档，也不会清空历史备份。

如需撤销已授予的权限，可在“系统设置 → 隐私与安全性 → 自动化”或“文件与文件夹”中关闭对应项目。

## 已知边界

- 已在上述验证环境完成自动化测试，并在另一台 Mac 完成安装及使用验收；其他 macOS 与 Office 版本仍建议先在可丢弃目录验证。
- Office 未安装、目标文件夹不可写或桌面权限被拒绝时，动作会显示错误原因。
- 为避免链接解析到真实文件，本版本不移动符号链接；桌面同名项目为符号链接时也不会自动处理。
- Finder 菜单显示位置和排序由 macOS 决定。

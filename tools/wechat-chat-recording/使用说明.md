# 聊天录屏工具 2.2 使用说明（macOS）

本工具把微信聊天录屏整理为三类成果：连续截图、可打印 PDF 和 Word 文字稿。原视频不会被修改；OCR 与语音识别默认在本机完成。

## 第一次使用

1. 解压安装包，不要只打开压缩包内的文件。
2. 双击 `安装或修复运行环境.command`。
3. 如果 macOS 提示安全限制：按住 Control 点按该文件，选择“打开”，再确认一次“打开”。
4. 等待显示“本机环境检查/准备完成”。默认不会下载任何语音模型；工具会优先使用本机已有的 MacWhisper 模型。

## 处理一段视频

1. 双击 `处理视频.command`。
2. 将一个录屏视频拖入出现的窗口，按回车。
3. 建议首次先输入 `y` 做预检：查看样张后，在成果目录的 `视频信息.json` 填写聊天类型、双方姓名或群成员昵称对应关系。
4. 再次双击处理同一视频，即会生成正式成果。

成果目录中只显示：

- `01_截图`：连续、无跳号的有效稳定截图；
- `02_可打印PDF`：适合打印或交付的 PDF；
- `03_文字稿/聊天记录.docx`：可编辑、可检索的 Word 文字稿。

## 批量处理多个视频

1. 双击 `批量处理视频.command`。
2. 将包含多个视频的文件夹拖入窗口，按回车。
3. 工具会逐段处理，并在 `聊天录屏工具批量成果/汇总` 中集中保存每段的 PDF 和 Word 副本。
4. 首次批量处理会生成 `成员名单.json`。可填写已确认的群名称、右侧/左侧姓名和“微信昵称=实名”对应关系，再重新批量处理。

未知头像成员会在每段视频中标为“未识别成员1、2……”。工具不会因为头像相似而跨视频自动认定为同一人，避免错误归属。

## 修改姓名，不重跑视频

双击 `修改人名并重新生成文字稿.command`，把成果文件夹拖入窗口。可修改双方姓名、群成员昵称对应关系、未识别成员分组和录制人姓名。该操作只重新生成 Word 文字稿，不重新读取视频、截图或转写语音。

## 语音和录制人说明

- 已播放的微信语音消息：只有画面气泡、播放动画和音频能够相互对应时，才会写入聊天正文。
- 录屏中的背景说明：默认不转写，避免把环境人声误当微信消息。需要时可由熟悉命令行的使用者开启 `--narrator auto`。
- 未填写录制人姓名时，文字稿只显示 `【录制人补充说明】`，不会擅自使用任何具体姓名。
- 混合音轨中的通知声、其他应用声音或重叠人声无法保证完全分离；相关内容应人工核对。

## 隐私与常见问题

- 原视频不改动；默认不上传聊天文字、音频或视频。
- 安装后如提示缺少本机环境，重新双击 `安装或修复运行环境.command` 即可。
- 每台 Mac 需各自安装运行环境；不要复制其他电脑的 `.venv`。
- 若 Word 显示异常，请确认已解压完整安装包，并重新运行“安装或修复运行环境”。

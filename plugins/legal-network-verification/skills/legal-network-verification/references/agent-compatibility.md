# Agent 兼容和降级规则

## 通用能力合同

完整流程需要：

1. 读取 `SKILL.md`、参考文件和本地输入；
2. 在用户授权范围内控制可交互浏览器，或接收用户提供的已脱敏证据；
3. 截取网页区域而非系统全屏；
4. 使用 Python 3.10+ 运行本地脚本；
5. 在需要时使用 Word 或 LibreOffice 渲染 DOCX。

运行 `doctor --browser available|unavailable|unknown` 检查本地 Python、依赖、随包模板和可选渲染器。浏览器能力由当前 Agent 或用户确认，脚本不尝试读取浏览器配置。

## 能力分级

| 浏览器 | 本地文件和 Python | 允许执行 | 不得声称 |
| --- | --- | --- | --- |
| 有 | 有 | 查询、页内截图、水印、结构化记录、Markdown、DOCX和本地审计 | 未完成或受限查询已完成 |
| 有 | 无 | 查询和保存用户确认安全的页面证据；把本地处理列为待办 | 已完成水印、DOCX或成果扫描 |
| 无 | 有 | 处理用户提供的已脱敏截图和查询记录，生成底稿 | Agent亲自查询了网站 |
| 无 | 无 | 制作网站清单、查询计划和空白记录 | 已查询、已留证或已生成正式底稿 |

## 平台说明

- Codex 可使用外层插件清单发现核心 Skill，也可直接加载核心目录。
- WorkBuddy 直接导入核心 Skill 目录；无法自动识别时手工指定 `SKILL.md`。导入 Skill 不等同于自动安装 Python、依赖或文档渲染器。
- 其他兼容 Agent 可导入同一目录；不支持自动发现时手工加载 `SKILL.md`。

业务规则、脚本、参考文件和资产只存在于核心 Skill。任何平台适配层不得复制或改写业务逻辑。

## 路径和运行环境

- 所有项目路径由用户或当前 Agent 显式传入，脚本不得假设用户目录、云盘目录或运行时目录。
- macOS/Linux 常见解释器命令为 `python3`，Windows 常见命令为 `py -3`；以当前 Agent 实际配置为准。
- 只在用户指定的工作底稿根目录及系统临时目录内写入。
- 浏览器、Word 或 LibreOffice 不可用时按能力分级降级，不自动安装系统软件。

## 兼容性声明

只有完成某平台的真实导入、触发和匿名输出测试后，才可表述为“已验证兼容”。只有结构检查时，应表述为“按该平台可导入的 Skill 目录设计，尚未完成运行时验证”。

# 网络核查法律依据与执业口径

## 使用说明

本文件仅提供公开版 Skill 的最低工作口径，不替代具体项目的现行法核验。下列官方链接于2026年7月17日复核可访问；正式法律意见、监管回复或规则发生变化时，应重新确认文件名称、文号、效力状态和条文内容。

用户指定的元典、商业数据库或既有检索记录，可以作为当次项目材料使用，但不是本 Skill 的固定依赖，也不得替代必要的官方网站现行性复核。

## 官方来源

### 《律师事务所证券法律业务执业规则（试行）》

- 发布文号：中国证券监督管理委员会、司法部公告〔2010〕33号。
- 第九条、第十条要求查验前明确事项、程序和方法，并在实施后评价查验完成情况。
- 第十六条涉及查询方法和查询笔录；第三十九条至第四十一条涉及工作记录、工作底稿和归档。
- 政府法规页面：<https://policy.mofcom.gov.cn/claw/clawContent.shtml?id=2041>
- 中国证监会现行监管文件仍援引该规则，例如：<https://www.csrc.gov.cn/jilin/c103788/c7612457/content.shtml>

### 《律师事务所从事证券法律业务管理办法》

- 中国证监会、司法部令第223号，自2023年12月1日起施行。
- 第十三条、第十四条涉及查验计划和查询等查验方法；第十九条、第二十条涉及工作记录、工作底稿和保存。
- 中国证监会发布页及附件：<https://www.csrc.gov.cn/shanghai/c105565/c7443926/content.shtml>

### 《中华人民共和国证券投资基金法》

- 第一百零七条规定，律师事务所等接受基金管理人、基金托管人委托出具相关文件时，应当勤勉尽责，对所依据文件资料内容的真实性、准确性、完整性进行核查和验证。
- 中国人大网：<https://www.npc.gov.cn/c2/c12435/c12488/201905/t20190522_76340.html>

### 私募基金登记法律业务

- 中国证券投资基金业协会《私募基金登记备案相关问题解答（八）》明确，法律意见书应包含完整尽职调查过程描述，并可根据实际需要采用互联网及数据库搜索等方法，制作和保存工作记录及工作底稿：<https://www.amac.org.cn/governmentrules/zcgz_hygd/hygd_smjj_zhl/201912/t20191222_1038.html>
- 协会登记备案事项服务指南可能随业务系统和规则调整，应在具体项目中重新核验当前版本：<https://www.amac.org.cn/businessservices_2025/privatefundbusiness/gzdt/202206/P020220624620991535168.pdf>

## 对本 Skill 的落实

1. 内部 Markdown记录查询条件、结果、同名排除、限制及截图对应关系。
2. 正式 DOCX承载查询时间、地点、查询人、查询对象脱敏身份信息、查询载体和简洁结果，并保留查询人员签名栏。
3. 截图另行保存；截图编号只用于内部底稿和文件管理，不写入正式查询记录正文。
4. 网络查询属于公开信息核查和佐证方法，不当然替代身份证明、主管机关材料、当事人声明、访谈和其他书面证据。
5. 私募基金或其他非证券项目应结合适用规则和监管要求确定查验强度，不得不加分析地表述为证券业务全部条款当然直接适用。
6. 上述规则没有要求每份查询笔录单列复核人；项目整体讨论、复核和质量控制记录按适用规则及机构制度另行留存。

## 更新边界

- 官方链接可访问不等同于规则必然现行有效，引用前必须重新确认。
- 网站页面、附件地址或业务指南发生变化时，记录新的官方来源和核验日期，不静默改写既有项目结论。
- 用户提供的检索记录应标注来源和日期，只进入当次项目，不进入公共 Skill 的固定依据。

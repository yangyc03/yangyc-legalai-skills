# 敏感查询和任务清理规则

## 完整身份证号码

完整身份证号码不得进入聊天、Agent上下文、运行文件、Skill 生成或仍需处理的成果、日志、文件名、截图、水印或图片元数据。不得要求用户上传包含完整号码的材料供本 Skill 处理。用户在全部技术检查完成后自行补填的归档 DOCX 不再属于本 Skill 的成果或处理对象。

旧式15位和现行18位身份证号码均按完整身份证号码处理。由 Agent 或 Skill 留存、读取或继续处理的成果仍只使用下述18位脱敏显示形式；正式记录的人工填写位置可以在 Skill 交付前保持空白。

正式成果中的脱敏身份证号码必须为18位显示形式：前10位数字不变，末8位统一替换为 `*`，例如 `1101011990********`。

## 查询前确认

目标网站确需完整号码时，Agent必须暂停并向用户显示以下提示：

> 我确认有权在本次查询中使用该查询对象的身份证号码；完整号码由我本人在目标网页中输入并提交，不发送至聊天，不由 Agent 或 Skill 保存、读取或上传；查询结束后清除输入并删除未脱敏临时材料；由 Agent 或 Skill 留存、读取或继续处理的成果仅显示末8位遮挡的身份证号码。正式记录确需完整号码的，我只在全部技术检查完成后自行补填，并不再将补填版交给 Agent 或 Skill。

用户必须作肯定确认。该确认仅适用于当前任务中的特定对象和特定网站；对象或网站变化后重新确认。确认文本不写入运行文件和正式工作底稿。

## 人工接管

1. Agent先定位查询页面和所需字段，但不聚焦、读取或填充身份证号码字段。
2. Agent暂停，由用户手工输入和提交完整号码，并完成验证码、短信、滑块或人脸验证。
3. 用户检查结果页是否显示完整号码。
4. 用户明确确认页面安全后，Agent才能恢复导航或截图。

Agent不得读取、导出或保存Cookie、密码、Token、浏览器自动填充内容和会话存储，不得绕过网站安全措施。

## 截图分支

- 页面不显示完整号码，或网站已按要求脱敏：可以截取网页区域并制作水印版。
- 页面显示完整号码：禁止Agent截图。用户可以在本地制作末8位遮挡的副本，再将脱敏副本作为输入。
- 无法安全制作脱敏副本：不留存截图，在查询记录中写明“因敏感信息保护未留存该页面截图”，使用 `capture_kind: not_retained_sensitive_page`。

不得通过裁切隐藏号码同时裁掉识别查询条件、网站来源或结果所必需的上下文。

## 任务结束

Agent应提示用户确认：

1. 已清空身份证号码输入框；
2. 已退出或关闭敏感页面；
3. 已删除未脱敏临时截图和副本；
4. 未把完整号码保存到聊天或任何仍会交由 Agent 或 Skill 处理的文件。

随后运行 `artifact-audit`。扫描不通过时不得宣布任务完成。

Skill只能检查其控制的文件和输出，不能保证删除目标网站记录、浏览器历史或缓存、操作系统缓存以及第三方服务日志。

## 对外文件

Skill 只生成不含完整身份证号码的版本。监管或其他正式文件确需完整号码的，由用户在 Skill 完成成果审计、结构检查和逐页渲染后自行填写；填入完整号码后的归档文件立即退出本 Skill 的处理范围，不得再次交由本 Skill 读取、渲染、截图、审计或复核，Skill 也不得声称已验证补填内容或归档版。

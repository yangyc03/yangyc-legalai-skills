# 查询网站配置

## 总则

- 配置用于选择查询方向，不把网址视为永久固定值；执行时记录实际打开的网址和查询入口。
- 优先法院、监管机关、政府和法定公示平台。搜索引擎仅用于发现原始来源，搜索摘要不能直接作为事实依据。
- 企查查等第三方平台仅在用户提供报告或明确授权时使用，并与官方来源区分。
- 网站不支持该主体类型时记录“查询对象不适用”，不得用空页面代替核查结论。

## `general-person`

| 核查方向 | 优先来源 | 说明 |
| --- | --- | --- |
| 裁判文书 | 中国裁判文书网 | 按姓名、期间及用户授权的身份要素交叉检索 |
| 执行和失信 | 中国执行信息公开网 | 仅姓名命中通常属于同名候选，必要时经授权使用精确身份条件 |
| 证券监管 | 中国证监会官网 | 官网全文检索姓名并核对任职机构、地域等身份锚点 |
| 证券期货失信 | 证券期货市场失信记录查询平台 | 记录是否支持姓名或证件条件及页面是否明确显示零结果 |
| 行业任职和诚信 | 相应行业协会或主管机关公示 | 只有姓名与任职机构等同时匹配才作明确匹配 |
| 信用公示 | 信用中国等 | 普通自然人姓名不属于适用条件时记录不适用 |

## `general-company`

| 核查方向 | 优先来源 | 说明 |
| --- | --- | --- |
| 主体登记和处罚 | 国家企业信用信息公示系统 | 优先完整名称或统一社会信用代码 |
| 信用和行政公示 | 信用中国及主管机关网站 | 核对主体名称、统一社会信用代码和处罚决定信息 |
| 裁判文书 | 中国裁判文书网 | 使用完整公司名称并记录期间 |
| 执行和失信 | 中国执行信息公开网 | 使用完整名称或统一社会信用代码等可用条件 |
| 破产事项 | 全国企业破产重整案件信息网 | 记录重整、和解、破产查询范围和结果 |
| 行业监管 | 行业主管机关、交易场所或协会网站 | 由项目类型决定是否启用 |

## `private-fund`

在对应主体的 `general-person` 或 `general-company` 基础上，增加：

- 中国证券投资基金业协会管理人和从业人员信息公示；
- 中国证监会官网；
- 证券期货市场失信记录查询平台；
- 与拟任职务、从业资格、诚信记录或管理人重大事项变更直接相关的协会公示入口。

基金业协会“诚信记录0”等字段只说明该公示页面相应栏目，不扩大解释为不存在司法、行政或其他市场负面事项。

## `custom`

用户指定网站时，逐项记录：

- 网站名称和实际网址；
- 查询目的；
- 适用主体；
- 查询关键词和筛选条件；
- 是否需要登录、验证码、付费授权或敏感身份条件；
- 查询结果和证据截图编号。

不得自行增加与项目无关的主体、网站或高成本数据源。

## 总则

- 配置用于选择查询方向，不把网址视为永久固定值；执行时记录实际打开的网址和查询入口。
- 优先法院、监管机关、政府和法定公示平台。搜索引擎仅用于发现原始来源，搜索摘要不能直接作为事实依据。
- 企查查等第三方平台仅在用户提供报告或明确授权时使用，并与官方来源区分。
- 网站不支持该主体类型时记录“查询对象不适用”，不得用空页面代替核查结论。
- 本文件中的登录、会话过期、验证、限流、结果加载和零结果文字仅是启发式提示，不是永久选择器或已核验页面事实。执行时必须按当次可见页面确认；布局或语义不明时失败关闭。
- `配置复核日期` 表示本 Skill 规则的整理日期，不等于真实网站页面的核验日期。只有实际页面核验后才填写页面核验日期；没有既有可靠记录的站点均明确标记“最近页面核验日期：未记录”。

## 访问与结果信号

按 `authenticated-browser-workflow.md` 只做页面级探测：

- 登录或会话信号：可见登录表单或按钮、跳转至登录路径、会话已过期提示、查询控件因认证不可用。
- 人工验证信号：验证码、短信、二维码、滑块、人脸、设备确认或其他需用户完成的挑战。
- 限流或权限信号：403、429、访问频繁、权限不足、付费可见、系统维护或服务异常提示。
- 结果已加载信号：本次查询条件仍可辨认，加载状态已经结束，并显示结果数量、结果列表或与该条件关联的明确空状态。
- 零结果信号：站点在当次页面上明确显示“0条”“暂无符合条件的结果”等等价语义；空白页、空表格、登录页中的数字“0”或仅无列表均不成立。
- 安全截图范围：只截取同时包含查询条件和结果状态的网页区域，排除账号区、密码区、验证码、二维码、完整身份证号码及不必要导航。

任何示例文字都必须在当次页面上核对语义，不得仅用字符串命中自动作出 `no_match_displayed`。

### 信用中国当前查询入口（2026-08-13 页面核验）

- 首页规范地址为 `https://www.creditchina.gov.cn/`，结果页规范地址为 `https://www.creditchina.gov.cn/xinyongxinxi/index.html`。schema 1.2 只保存结果页规范地址，不保存查询参数或片段。
- 当前首页搜索框提示为“请输入主体名称或者统一社会信用代码”。首页搜索按钮中心点可能被“信用修复”悬浮链接遮挡；命中检查发现遮挡时不得点击该按钮，也不得把进入 `/xyxf/xfzn/` 的信用修复指南页面记为查询已提交。此时保持 `submit_state=not_submitted`。
- 当次页面必须重新核验官方 `js2025/common2025.js` 的搜索处理与 `js/config/config.js` 中的 `config.FEIP`。只有两者仍明确指向同域结果页时，才允许执行一次直接导航；任一文件不可读、域名或契约变化、语义不明时失败关闭。
- 当前官方契约包含固定参数 `index=0`、`scenes=defaultScenario`、`tableName=credit_xyzx_tyshxydm`、`searchState=2`、`entityType=1,2,4,5,6,7,8`，以及百分号编码的 `keyword`。参数仅用于当次浏览器请求，不得持久化到运行文件、底稿或 DOCX。

- 当前页面核验中，搜索框回车未触发结果页，不能作为已验证的备用提交路径。页面或脚本变化后必须重新核验，不得据此长期固化选择器。

## `general-person`

自然人固定默认启用以下5类；表格之外的监管、失信扩展和行业来源均不因选择本 profile 自动加入范围。

### 固定默认

| 核查方向 | 优先来源 | 说明 |
| --- | --- | --- |
| 裁判文书 | 中国裁判文书网 | 按姓名、期间及用户授权的身份要素交叉检索 |
| 法院公告 | 人民法院公告网 | 按姓名和期间查询，结果需结合身份要素核对 |
| 执行 | 中国执行信息公开网 | 仅姓名命中通常属于同名候选，必要时经授权使用精确身份条件 |
| 失信 | 中国执行信息公开网 | 仅记录该网站公开栏目结果，不扩大解释为其他信用结论 |
| 限高 | 中国执行信息公开网 | 按网站实际栏目和已确认期间记录 |

| --- | --- | --- |
| 证券监管 | 中国证监会官网 | 只有用户在范围矩阵中明确确认后启用，并核对任职机构、地域等身份锚点 |

## `private-fund`

在对应主体的 `general-person` 或 `general-company` 基础上，增加：

- 中国证券投资基金业协会管理人和从业人员信息公示；
- 中国证监会官网；
- 证券期货市场失信记录查询平台；
- 与拟任职务、从业资格、诚信记录或管理人重大事项变更直接相关的协会公示入口。

自然人固定默认启用5类：裁判文书、法院公告、执行、失信、限高。行政/行业监管、市场禁入、自律处分必须由用户明确指定主管机关网站；不得从公司主体派生法定代表人、股东、高管、实控人或关联方作为自然人核查对象。

基金业协会“诚信记录0”等字段只说明该公示页面相应栏目，不扩大解释为不存在司法、行政或其他市场负面事项。

## `custom`

用户指定网站时，逐项记录：

- 网站名称和实际网址；
- 查询目的；
- 适用主体；
- 查询关键词和筛选条件；
- 是否需要登录、验证码、付费授权或敏感身份条件；
- 当次确认的登录、会话过期、人工验证、限流、结果加载及零结果启发式信号；
- 安全截图范围、配置复核日期和最近页面核验日期；没有可靠页面核验记录时写“未记录”，不得用配置日期冒充；
- 查询结果和证据截图编号。

不得自行增加与项目无关的主体、网站或高成本数据源。
